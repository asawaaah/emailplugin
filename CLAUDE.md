# CLAUDE.md

Extension Chrome « Aperçu Gmail » (Manifest V3) : badge des non lus, lecture et actions rapides sur plusieurs comptes Gmail. Usage personnel pour l'instant (application Google Cloud en mode test).

- **Langue** : répondre et documenter en français ; code et noms en anglais. Interface FR par défaut, EN en second (`src/lib/i18n.ts`, mettre les deux à jour ensemble).
- **Profil** : le porteur lit le code sans coder au quotidien ; expliquer les choix simplement, avancer par petites étapes vérifiables.
- **Avant chaque commit** : `npm run check` puis `npm run test:e2e` ; `extension/` (build) est versionné et doit être reconstruit.
- **Sécurité** : le corps des courriels ne s'affiche que dans l'iframe isolé (`buildEmailDocument`, sandbox sans `allow-scripts`), jamais via `innerHTML` dans les pages de l'extension. Images distantes bloquées par défaut. Aucune donnée de courriel ni adresse dans les journaux. Jetons dans `chrome.storage.session` seulement.
- **Notifications** : style par défaut « bulle dans l'onglet », en haut à droite. Le script injecté (`src/content/toast.ts`) ne reçoit aucun contenu de courriel : il pose seulement, dans un Shadow DOM fermé, un cadre de l'extension (`bubble.html`, `web_accessible_resources`) qui lit la file lui-même et ne s'affiche qu'avec le jeton à usage unique (`bubbleToken`) et l'onglet (`toastTabId`) fixés par le service worker. Repli sur la notification du système si la page refuse l'injection. La file (`chrome.storage.session`, clé `toasts`) n'est modifiée que par le service worker, via `serialized()`. Affichage commun bulle et petite fenêtre : `src/lib/toast-view.ts`.
- **Messages** : le service worker n'écoute que les pages de l'extension (`sender.url` sous `chrome.runtime.getURL('')`) ; le script injecté dans les sites ne lui envoie rien. Ne jamais relâcher ce contrôle (il protège les jetons Gmail).
- **Relais** (`relay/worker.js`, Cloudflare Workers) : ne transmet qu'un Web Push **sans contenu** ; n'envoie qu'aux services de push connus (pas de rebond vers d'autres sites) ; clé `RELAY_SECRET` comparée à temps constant. Côté extension, une alerte ne fait que déclencher `pollAll()` : ne jamais lui faire confiance pour autre chose. Abonnements Gmail (`users.watch`) renouvelés toutes les 12 h (`gmail-watch`).
- **Connexion** : toujours dans le service worker (le popup se ferme quand la fenêtre Google prend le focus). Portée unique `gmail.modify` ; jamais de suppression définitive.
- **Identifiant de l'extension** fixé par la clé du manifest : `icpofmgbmnhgejjklblpnnloenedaffp` (URI de redirection déclarée chez Google). Ne pas changer la clé.
